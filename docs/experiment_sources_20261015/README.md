# Historical execution sources

These are the exact research scripts used to obtain the mechanism records.
They are supplied for algorithm/protocol inspection, not as portable launchers:
they expect the original historical directory layout, response matrices,
checkpoint metadata and heat caches, which are not bundled. Their original
location is research/mechanism_completion_20261015 under a completed research
workspace. Site-specific queues are omitted. Use the public explicit-input
sampling/rendering entry points in research/mechanisms for new experiments.
The immutable scalar results support summary reproduction without these assets.
